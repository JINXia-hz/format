# 磁盘格式化工具 (Disk Format Tool)

一个带有趣味安全保护机制的 Linux 磁盘格式化脚本。

## 项目简介

本工具用于格式化 Linux 系统中的非系统分区磁盘，支持多种文件系统类型。内置的 `security.sh` 安全模块提供了独特的"面壁思过"惩罚机制，让格式化操作不再枯燥。

## 功能特性

- 🛡 **安全保护机制** — 首次运行需签署免责声明，确认风险
- ⏳ **面壁思过系统** — 违规操作会触发趣味惩罚，包含随机武侠风格面壁词
- 🔗 **哈希链日志** — 所有操作记录通过 SHA256 哈希链保护，防止篡改
- 📝 **Merkle 树审计** — 生成 Merkle 树日志，便于完整性验证
- 💾 **多文件系统支持** — 支持 xfs、ext4、btrfs、ntfs 等多种格式
- 🔄 **两种操作模式** — 交互确认模式 / 自动模式
- 🎲 **PoW 赎罪机制** — 可通过工作量证明减少违规计数

## 支持的文件系统

| 文件系统 | 命令 |
|---------|------|
| xfs     | mkfs.xfs -f |
| ext4    | mkfs.ext4 -F |
| ext3    | mkfs.ext3 -F |
| ext2    | mkfs.ext2 -F |
| btrfs   | mkfs.btrfs -f |
| ntfs    | mkfs.ntfs -F |
| fat32   | mkfs.fat -F32 |

## 使用说明

### 1. 首次运行

首次运行需要签署免责声明：

```bash
sudo ./cipan.sh
```

按照提示输入 `yes` 确认风险后，即可获得使用权限。

### 2. 正常使用

```bash
# 交互模式（默认，每个磁盘格式化前询问确认）
sudo ./cipan.sh

# 或指定模式
sudo ./cipan.sh 1   # 交互确认模式
sudo ./cipan.sh 2   # 自动模式
```

### 3. 运行流程

1. 脚本自动列出所有磁盘信息
2. 选择确认模式（交互/自动）
3. 选择文件系统指定方式（统一格式/单次指定）
4. 自动跳过系统盘和已挂载的磁盘
5. 执行格式化操作

## 安全机制

### 契约签署
首次运行必须签署免责声明，确认已了解格式化风险。

### 违规惩罚
- 拒绝签署声明 → 触发惩罚计时
- 多次无效输入 → 违规计数增加
- 篡改状态文件 → 签名校验失败，惩罚加倍

### 面壁思过
惩罚期间会显示随机武侠风格面壁词，如：
- "你盯着墙上的划痕，突然悟出了独孤九剑的第一式，剑法 +1"
- "小师妹偷偷跑来找你，塞给你一个热乎的烤地瓜，心情 +5，饱食度 +10"

### 日志审计
所有操作记录通过 SHA256 哈希链保护，并生成 Merkle 树日志，确保日志不可篡改。

## 文件说明

| 文件 | 说明 |
|------|------|
| `cipan.sh` | 主脚本，磁盘格式化逻辑 |
| `security.sh` | 安全保护模块，包含惩罚机制和日志系统 |

## 注意事项

> ⚠ **格式化操作不可逆，数据将永久丢失！**
>
> 使用前请仔细核对磁盘信息，误操作可能导致数据丢失。
> 本脚本会自动跳过系统盘和已挂载的磁盘，但仍需谨慎使用。
